## Highlights ⭐️

* **A graph of your MCP estate**: `passmcp-graph ingest` reads passmcp's attestations and reports and your MCP client configurations into one local graph of agents, servers, tools and identities, without storing a credential.
* **Inherited risk and over-privilege**: `passmcp-graph analyze` names each agent that reaches a server with a failing critical check, and each identity holding write or admin scopes where every tool is read-only.
* **Queries and policy gates**: `passmcp-graph query "agents -> tools where destructive and server.auth = none"` answers from the graph, and `passmcp-graph check --policy policy.yaml` exits 1 on any forbidden path.
* **Export for other tools**: JSON in the published graph format, GraphML and Cypher, all offline.

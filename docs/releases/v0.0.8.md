## Highlights ⭐️

* **`dashboard --assets` for strict hosts**: the page's stylesheet and script are written beside `--out` as `dashboard.css` and `dashboard.js` and linked from the page, for a web server whose Content-Security-Policy refuses inline code. Behind such a header the single-file page showed as unstyled shapes with no behaviour. The default single file is unchanged, and no element in either form carries a `style` attribute.
* **The dashboard is rebuilt on the Control Centre theme**, with Skeletonic Stylus 3.0.0's core embedded unmodified: a sidebar that becomes a menu below 1024 pixels, the critical-finding banner, the status ring, KPI tiles and severity pills. Every figure, filter, link, export and theme setting works as before.
* **Each server has one name across the dashboard**: the banner, findings, evidence gaps, mitigation steps and links use the name the server reports, or its endpoint when there is none, as the command centre does. In `--format json`, `server.name` changes the same way.
* **In lockstep with passmcp 0.0.8**, the family's eighth release: passmcp-reporting is required at v0.0.8, and passmcp's trace runs at v0.0.8. The other commands, the query language, the policy file, the graph format and the exit statuses are the ones 0.0.7 shipped.

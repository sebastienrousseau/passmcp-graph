## Highlights ⭐️

* **Fuzzed query parser**: any text given to `passmcp-graph query` or a policy file either fails with an error or parses to a query that reads back the same way, and evaluating it never crashes; `go test -fuzz=FuzzParse ./internal/query` runs the check.
* **Fuzzed secret redaction**: a fuzz target puts a generated secret in every place an MCP client configuration can hold a credential and checks that `ingest` never copies it into the graph.
* **Same interface, family release**: the commands, query language, policy file, graph format and exit statuses are unchanged from 0.0.2; this release moves passmcp-graph with the rest of the passmcp family.

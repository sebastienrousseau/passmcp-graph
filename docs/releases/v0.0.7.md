## Highlights ⭐️

* **Built with Go 1.26.9**: the release binaries move off Go 1.26.8, which has five open `net/http` advisories that 1.26.9 fixes. passmcp-graph runs no HTTP server and sends no request; the binaries still should not carry them.
* **In lockstep with passmcp 0.0.7**, the family's seventh release: passmcp-reporting is required at v0.0.7, and passmcp's trace runs at v0.0.7. passmcp 0.0.6 had no passmcp-graph release, so the upgrade is from 0.0.5.
* **An offline dashboard**: `passmcp-graph dashboard --open` writes one self-contained page that leads with the item to look at first and its evidence, then the exact client, server and tool paths, the attention items, and details for every server, client and identity. Filters scope every count, and the page prints the `query` command that returns what it shows. It loads nothing from the network, and `--share-safe` replaces identifying details before it is shared.
* **`ingest` accepts a sha512 subject digest**, following passmcp-reporting 0.0.6: a statement carrying only sha512 is ingested, and one whose sha512 does not match is refused. Server IDs are unchanged. The other commands, the query language, the policy file, the graph format and the exit statuses are the ones 0.0.5 shipped.

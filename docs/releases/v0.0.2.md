## Highlights ⭐️

* **Shell completions**: `passmcp-graph completion bash|zsh|fish` prints a completion script built from the command table, and `make install` installs the binary and all three scripts under `PREFIX`, staged under `DESTDIR` for packagers.
* **Release archives**: each release now attaches archives for Linux, macOS and Windows on amd64 and arm64, with a cosign-signed `checksums.txt` and SLSA build provenance you can check with `gh attestation verify`.
* **Lockstep with the family**: passmcp-graph requires passmcp-reporting at the family's release version, and `make versions` fails when any file names a different one.

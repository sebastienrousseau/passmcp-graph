## Questions and discussion

This repository has no discussion forum. Ask a "how do I" question, or
raise an open-ended idea, as a
[GitHub issue](https://github.com/sebastienrousseau/passmcp-graph/issues/new/choose)
with the feature-request template. A question about a verdict itself —
why passmcp judged a server the way it did — belongs in
[passmcp's issues](https://github.com/sebastienrousseau/passmcp/issues),
because passmcp-graph only reads what passmcp attested.

## Bugs and feature requests

[GitHub Issues](https://github.com/sebastienrousseau/passmcp-graph/issues),
using the templates. A good report includes what `passmcp-graph version`
printed, the command, its output and exit status, and the smallest input
that reproduces it, with secrets removed.

## Security

**Do not open a public issue for a vulnerability.** Follow the private
reporting process in [SECURITY.md](SECURITY.md).

## Response expectations

passmcp-graph is maintained by one person alongside other work. Issues are
read within a week; security reports are prioritised per the SLA in
SECURITY.md. There is no commercial support offering.
